# PARK ME – חונים במכללה

PARK ME היא אפליקציה שמראה לסטודנטים במכללה האקדמית תל אביב-יפו אילו חניות בחניון המכללה פנויות. סטודנטים מדווחים על כניסה (check-in) כשהם חונים ועל יציאה (check-out) כשהם עוזבים, וכך כולם רואים את תפוסת החניון בזמן אמת.
החניון כולל 200 חניות ב-10 שורות (A–J), ובהן חניות נכים, חניות סגל שמורות וחניות טעינה לרכב חשמלי.
השרת בתרגיל זה בנוי ב-Node.js וב-Express ומחזיר נתונים קבועים בפורמט JSON עבור שתי ישויות: חניות (spots) וחניות שבוצעו (parkings).

## נתיבים (Routes)

| HTTP | URL | מה מוחזר |
|---|---|---|
| GET | `/` | הודעת פתיחה ב-JSON: שם הפרויקט, תיאור קצר ורשימת הנתיבים הזמינים |
| GET | `/api/spots` | מערך של כל 200 החניות בחניון |
| GET | `/api/spots/summary` | סיכום: פנויות / תפוסות / שמורות / מדווחות, חניות פנויות לפי שורה (A–J) ולפי סוג |
| GET | `/api/parkings` | מערך רשומות חנייה (היסטוריית החניות של נועה כהן וחניות פעילות של סטודנטים אחרים) |
| GET | `/api/parkings/active` | רק החניות הפעילות כרגע (ללא שעת יציאה) |
| GET | כל כתובת אחרת | סטטוס `404` ו-`{ "error": "Route not found", "path": "<הנתיב שהתבקש>" }` |

## הרצת השרת

דרישות: Node.js מותקן במחשב.

```bash
cd park-me-server
npm install
npm start
```

השרת עולה בכתובת `http://localhost:3000`
